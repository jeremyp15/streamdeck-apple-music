# Apple Music for Stream Deck

Stream Deck plugin (`com.spud.applemusic`) for controlling Apple Music: play/pause, next, now playing, repeat, shuffle, volume and scrub.

- Source: `com.spud.applemusic.sdPlugin/`
- Installable build: `dist/com.spud.applemusic.streamDeckPlugin` (double-click to install)

Manifest: Apple Music | 1.1.0.0
