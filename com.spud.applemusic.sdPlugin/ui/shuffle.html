When the media session reports shuffle is enabled, the key calls the Windows shuffle control and shows On or Off.
Apple Music on Windows usually does not publish shuffle. This key then focuses the Apple Music window and sends Apple's access key: Alt, then L, then S, one key after another. That is not Ctrl+S. The app does not report the result, so the key stays on the neutral Shuffle icon. A song needs to be playing before Apple Music accepts it. Other players are not sent this shortcut.
