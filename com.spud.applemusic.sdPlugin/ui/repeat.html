When the media session reports repeat is enabled, the key reads the current mode and cycles Off, All, and One through Windows.
Apple Music on Windows usually does not publish repeat. This key then focuses the Apple Music window and sends Apple's access key: Alt, then L, then R, one key after another. Each press cycles the in-app control once. The app does not report the mode, so the key stays on the neutral Repeat icon. A song needs to be playing before Apple Music accepts it. Other players are not sent this shortcut.
